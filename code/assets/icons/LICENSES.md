# Icon font licences

The fonts in this folder are trimmed copies of fonts shipped with `@expo/vector-icons`
(react-native-vector-icons). Each keeps only the glyphs listed in `glyphs.json`; nothing else was
changed. They are rebuilt with `scripts/subset-icon-fonts.py`.

## FontAwesome5.ttf — Font Awesome Free 5 (Solid)

Copyright Fonticons, Inc. The font files are licensed under the SIL Open Font License 1.1:
https://scripts.sil.org/OFL — the icons themselves under CC BY 4.0. Source:
https://fontawesome.com/license/free

This is a modified (subset) version. As the OFL reserves the name "Font Awesome" for the original,
the trimmed font is named `PastVuFontAwesome5Solid`.
